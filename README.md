<h1>◈ DataLens</h1>

<h3>CSV Analysis Dashboard</h3>

<p>
<sub>
<strong>DataLens</strong> is a lightweight, privacy-first CSV analysis dashboard that runs entirely in your browser. Upload a CSV file and instantly explore statistics, data-quality warnings, interactive SVG charts, searchable and sortable tables, and intelligent insights through a polished glassmorphic interface. <strong>No server, no data sharing, just instant analytics.</strong>
</sub>
</p>

<hr>

<p>
<sub>
⚡ <strong>Core Capabilities</strong> · Drag-and-drop CSV parsing with quoted fields and comma-separated data · Automatic statistics including row count, missing values, duplicates and column types · Data-quality warnings for high-null columns, constant columns and potential unique IDs · Interactive Bar, Line, Pie and Scatter charts rendered using SVG · Global search, per-column filters and sortable tables · Custom chart builder with X/Y axis selection · CSV export of visible or filtered data · Multiple dataset support with tabbed switching · Persistent Dark/Light theme using <code>localStorage</code>.
</sub>
</p>

<p>
<sub>
🧩 <strong>Technology Stack</strong> · HTML5 · CSS3 · Vanilla JavaScript · SVG · localStorage · <strong>No frameworks, no backend, no dependencies and no build process.</strong>
</sub>
</p>

<p>
<sub>
🚀 <strong>Quick Start</strong> · Open <code>index.html</code> → drag and drop a CSV file → explore your data. No installation or build command required.
</sub>
</p>

<p>
<sub>
📊 <strong>Visualization</strong> · DataLens automatically recommends useful visualizations including Bar Charts for comparisons, Line Charts for trends, Pie Charts for distributions and Scatter Plots for relationships between numerical variables. The Custom Chart Builder allows users to manually select X and Y axes.
</sub>
</p>

<p>
<sub>
🔍 <strong>Data Quality</strong> · Automatically detects missing values, constant-value columns, potential unique identifiers, duplicate records and column types, helping users understand dataset quality before analysis.
</sub>
</p>

<p>
<sub>
🔎 <strong>Data Exploration</strong> · Search the complete dataset, filter individual columns, sort records and export visible or filtered data as CSV.
</sub>
</p>

<p>
<sub>
⌨️ <strong>Keyboard Shortcuts</strong> · <code>Ctrl + K</code> / <code>⌘ + K</code> → focus search · <code>ESC</code> → close modal.
</sub>
</p>

<p>
<sub>
🔐 <strong>Privacy First</strong> · Your CSV is processed entirely inside your browser. There is no backend server, database, file-upload API, external data sharing or account requirement.
</sub>
</p>

<p>
<sub>
💾 <strong>Multiple Datasets</strong> · Load multiple datasets and switch between them using tabs without uploading your data to a server.
</sub>
</p>

<p>
<sub>
🎨 <strong>Interface</strong> · Modern glassmorphic analytics interface with dark-first design, neon accents, responsive layout, smooth interactions and Dark/Light theme support.
</sub>
</p>

<p>
<sub>
📁 <strong>Project Structure</strong> · <code>index.html</code> · <code>style.css</code> · <code>script.js</code> · <code>README.md</code>
</sub>
</p>

<p>
<sub>
🌟 <strong>Why DataLens?</strong> · Most CSV viewers simply display rows and columns. DataLens turns a CSV file into an interactive analytical workspace, helping users quickly understand dataset size, missing values, duplicates, column types, patterns and relationships while allowing them to search, filter and export data.
</sub>
</p>
